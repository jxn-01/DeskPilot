# Synthetic Support Guides

These guides are fictional demo material. They are not operational instructions. The prototype must show the guide title beside any recommendation and must not invent steps that are not in these guides.

## VPN Connectivity

For a routine VPN connection problem, ask whether the user can reach other company services. Have them disconnect and reconnect using the approved company VPN client, then check the company service-status page. If the issue continues, route the ticket to the IT network support queue. Do not ask the user to share credentials.

## Account Recovery and Access Requests

For a locked account, direct the user to the approved company account-recovery page. Never request a password, one-time passcode, or recovery code in a ticket or chat. Do not unlock accounts on the user's behalf.

Requests for shared mailbox or other restricted access must follow the company's access-request process and require the appropriate manager approval. Do not grant access based only on a ticket statement.

## Security Incident Reporting

If a user entered their password on a suspicious page, opened an unexpected attachment, or reports a security warning, route the ticket to the security team immediately. Tell the user not to forward the suspicious link or attachment to other people. Do not ask them to investigate, delete evidence, or change security settings unless the security team instructs them to do so.

## Software Installation

Software installation must use the approved software catalog and company approval process. Remote-access tools require explicit approval. Do not recommend downloading or installing unapproved software. Route approval questions to the IT software support queue.
